CACH LAY FILE APK (khong can may tinh manh)
1. Tao tai khoan GitHub (mien phi) -> New repository (de Private cung duoc).
2. Bam "uploading an existing file", keo THA TOAN BO noi dung thu muc DocSach (gom ca thu muc .github) vao -> Commit.
3. Vao tab Actions -> doi "Build APK" chay xong (3-6 phut) -> mo lan chay do -> muc Artifacts -> tai "DocSach-apk".
4. Giai nen, copy app-debug.apk vao dien thoai, mo len, cho phep "cai tu nguon khong ro" -> Cai dat.
Hoac: mo thu muc nay bang Android Studio -> Build > Build APK(s).

LUU Y KHI DUNG:
- Lan dau mo app, bam "Cho phep" thong bao de app doc duoc khi tat man hinh.
- Vao Cai dat > Pin > Doc Sach > chon "Khong han che" (neu may tu tat app nen).
- Neu chua co giong Viet: mo app > Aa > "Cai / chon giong Google tieng Viet" > chon Google Speech Services > Tieng Viet.
